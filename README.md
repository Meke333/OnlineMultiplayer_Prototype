# ABOUT THE GAME
This is a boxing/fighting game, where you and another player punch the opponent until they go down. You can throw jabs, hooks and gut punches for either the left or right side, block the incoming attacks or dodge them to get the upper hand of your opponent. This endless game has a scoring system, which tracks how many times a player has knocked down the other one.

# CONTROLS
### Offense
Left Punch - [J]
Right Punch - [K]
Aim with **Punch** Input (being Left or Right Punch):
Hook - [▲]/[W] + Punch
Gut - [▼]/[S] + Punch

### Defense
#### Dodging
Dodge Left - [◄]/[A]
Dodge Right - [►]/[D]

You can dodge the incoming left and right attacks with dodging left and right accordingly. (If the opponent throws a left attack, the player needs to dodge right and vice versa)

#### Blocking
Block - [Space]

You can block all punches if you hold the Block button and stand still (no dodging, no punching), but you still receive some reduced damage.

# PREREQUISITES
This game only works on Windows. You need two separate PCs for each player that can connect to the internet.

# HOW TO START PLAYING
### Starting the Game
Either download the game's folder "Build" and open up the executable in the "Build" folder and the game opens up.
Or
Open up the Unity Project (install the corresponding Unity Version '6000.2.7f2') and press Play or Build it with the already existing settings

### Setting up Player
Under "Name & Character!":
At the top of the screen you see an inputfield and a dropbox.
Enter a name into the Inputfield.
A name is needed in order to play the game.

Choose which Glove Color you want with the dropbox:
- Character A has red gloves
- Character B has blue gloves

### Hosting a Game
Under "Create a Game!":
You can host your own game with the "Host a Game!" button.
You can also create a private server which you can't access publically and can only enter with a Join Code. (You will find it under the black score board)

This game requires 2 Players in one session.
If you have hosted a game you need to wait for one additional player to enter your game.

### Joining a Game
Under "Find & Join a Game!"
You have two methods of joining an existing hosting game.
1. Enter with a Join Code that the Host provided. Enter the code in the inputfield and press the "Join a Game!" button to enter.
2. Press the "Search for a Game!" button and select the Game you wanna join in the panel that opens up.
